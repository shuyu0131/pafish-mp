# 纸鱼博客小程序「纸鱼手帐」全方位升级方案

> 版本：v1.0（方案稿）  
> 日期：2026-10-23  
> 基线：`main` @ `ed2193b`  
> 范围：微信小程序前端（uni-app + Vue3 + Vite + TDesign），不改动 `/mp/*` 接口契约  
> 研究样本：本地 10 个页面、8 个业务组件；Gitee `ananyouu/yimo-resource-blog` 源码与 15 张小程序截图

> **视觉方向已修订（2026-10-23）**：V1 的「纸鱼手帐」暖纸/墨绿方向经评审后不再采用，视觉部分以 [`UI-UPGRADE-PLAN-V2.md`](./UI-UPGRADE-PLAN-V2.md) 为准。  
> 本文件的信息架构、接口约束、技术实现、排期与验收中**非视觉部分**仍然适用。

## 0. 结论先行

### 0.1 一句话方案

把现在「TDesign 默认白底列表」的纸鱼博客，升级为有明确品牌记忆的「**纸鱼手帐**」：**暖纸底 + 鱼蓝主色 + 珊瑚强调 + 手绘线性图标 + 编辑式排版**。保留现有功能、开关和接口，重做视觉层、页面骨架和内容呈现方式。

### 0.2 六个关键决策

1. **不照搬参考站。** yimo 的资源站值得学的是「沉浸式头图、卡片节奏、图标语言、自定义底栏、发现页、个人页运营位」，不是它的广告位、积分任务、拼图封面和高饱和配色。
2. **做「纸感编辑风」，不做「卡通资源站」。** 纸鱼是个人博客，阅读体验和品牌气质优先。视觉关键词：纸感、海盐、手帐、留白。
3. **首页、详情、我的三页先立住。** 其他页面沿用同一套 token 和组件，避免“首页精修、内页原样”。
4. **信息架构从 3 Tab 升为 4 Tab。** 文章 / 微语 / 发现 / 我的，搜索页升级为「发现」页，承接搜索、热词、分类和推荐。
5. **去 TDesign 默认皮肤，不盲目去 TDesign。** 保留 `t-icon`、`t-popup` 等低层能力，替换 `t-tab-bar`、`t-empty`、`t-skeleton`、`t-search` 等强视觉组件，减少样式隔离和“默认蓝”残留。
6. **资源预算是硬约束。** 当前包内图片 124K，其中默认横幅 116K；升级目标 ≤ 180K，默认横幅改为远程/配置化，包内只留品牌图形和少量插图。

### 0.3 预期效果

| 维度 | 现在 | 升级后 |
| --- | --- | --- |
| 首屏 | 搜索框 + 分类 chips + 列表 | 品牌导航 + 编辑精选头图 + 分类胶囊 + 卡片流 |
| 文章详情 | 原生导航 + 纯文字正文 + 行内操作 | 沉浸式头图 + 阅读进度 + 编辑式正文 + 固定操作栏 |
| 我的 | 身份卡 + 统计 + 菜单 | 个人头图 + 数据卡 + 四宫格入口 + 品牌化菜单 |
| 导航 | 系统导航 + TDesign 底栏 | 自定义导航 + 自定义 4 Tab 底栏 |
| 空态/加载 | TDesign 默认空态/骨架 | 纸鱼插图 + 匹配布局的品牌骨架 |
| 包内图片 | 124K | 目标 ≤ 180K，红线 200K |
| 代码层 | 47 处硬编码颜色 | 全部走 token，页面零品牌色硬编码 |

## 1. 现状研究

### 1.1 页面与组件清单

| 页面 | 路径 | 现有实现 | 主要问题 |
| --- | --- | --- | --- |
| 首页 | `src/pages/index/index.vue` | 原生搜索入口 + 分类 chips + 单张横幅 + 通栏文章行 | 无品牌头图；横幅是单张实拍图；文章行无卡片层次；首屏信息密度低 |
| 微语 | `src/pages/micro/index.vue` | 单栏白底列表，`zz-micro-item` 行内点赞/分享 | 与首页同构，缺少时间流气质；卡片边界弱 |
| 搜索 | `src/pages/search/index.vue` | `t-search` + 热门标签 + 历史 + 结果行 | 只是工具页；没有“发现”内容；与首页搜索入口重复 |
| 文章详情 | `src/pages/post/detail.vue` | 原生导航 + 标题/作者/正文 + 行内操作 + 评论区 | 无头图、无阅读进度、无固定操作栏；正文样式是 TDesign 灰阶 |
| 我的 | `src/pages/mine/index.vue` | 白底身份卡 + 统计卡 + 菜单列表 | 像设置页；无个人头图；入口没有视觉分区 |
| 我的收藏 | `src/pages/mine/favorites.vue` | 通栏列表 + 取消收藏 | 与首页列表重复；无收藏夹气质 |
| 我的评论 | `src/pages/mine/comments.vue` | 白底卡片 + 原文引用 | 信息层级平；待审核状态不突出 |
| 浏览历史 | `src/pages/mine/history.vue` | 按天分组 + 逐条删除 | 列表过密；无时间轴/缩略图节奏 |
| 设置 | `src/pages/settings/index.vue` | 分组白卡 + 菜单行 | 通用设置页观感；分组标题弱 |
| 关于 | `src/pages/settings/about.vue` | 品牌卡 + 内容/订阅/版本/链接分组 | 信息完整但缺少品牌收束 |

业务组件：`zz-card`、`zz-article-row`、`zz-micro-item`、`zz-avatar`、`zz-comment-item`、`zz-section-head`、`zz-tabbar`、`zz-login-sheet`。

### 1.2 视觉审计

**色彩**

- 全局 token 在 `src/App.vue`，当前是 TDesign 默认品牌蓝 `#0052d9`、纯白页面、`#e7e7e7` 分割线。
- 页面内仍有 47 处 `#0052d9` / `rgba(0,0,0,.4)` 等硬编码颜色，集中在图标颜色、错误重试、点赞态、`mdcss.js` 正文样式。
- 分类封面占位是统一中性灰，缺少识别度；分类 chips 只有“选中/未选中”两种状态。

**布局**

- 主流页面是「白底 + 通栏行 + 1rpx 分割线」；`zz-card` 多数以 `r="0"` 使用，实际没有卡片层次。
- 首页没有头图/精选位；横幅仅一张 `banner-1.jpg`，且只有全部分类下显示。
- 详情页操作区跟在正文后面，长文读完后才能点赞/收藏；没有固定操作栏。
- 我的页是“身份卡 + 统计 + 菜单”的直线堆叠，缺少入口分区和视觉焦点。

**字体与排版**

- 正文 28rpx，标题 30–40rpx；字重、行高、段间距没有形成编辑式层级。
- 正文 `mdcss.js` 使用灰阶：代码块 `#f6f6f6`、引用 `#f7f7f7`、链接默认蓝，和“纸鱼”气质无关。
- 缺少阅读时长、阅读进度、文章结尾标记等阅读场景细节。

**导航与组件**

- 系统原生导航栏，页面标题由 `pages.json` 配置；没有品牌露出。
- 底栏是 `t-tab-bar`，3 个 Tab，切换用 `uni.reLaunch`。
- `t-empty`、`t-skeleton` 使用 TDesign 默认样式，和品牌无关。
- `t-search` 样式隔离严重，首页/微语只能用原生 `view` 模拟搜索框，形成两套观感。

**状态与动效**

- 只有基础的加载/空/错误三态；没有品牌化空态插图，错误态只是文字 + 重试。
- 没有页面进入动效、点赞反馈、Tab 切换动效、骨架到内容的过渡。
- 下拉刷新是系统默认样式，背景色/提示文字没有跟随品牌。

### 1.3 代码层问题

| 问题 | 证据 | 影响 |
| --- | --- | --- |
| 品牌色硬编码 | `grep '#0052d9'` 命中 13 个文件 | 换肤/暗色/一致性成本高 |
| 组件视觉不统一 | `zz-card` 多数 `r="0"`，页面各自写行样式 | 改一处无法全局生效 |
| 双搜索框实现 | 首页/微语用 view 模拟，搜索页用 `t-search` | 观感与交互不一致 |
| 正文样式硬编码 | `src/common/mdcss.js` 中 `BRAND = '#0052d9'`、灰阶 | 正文与阅读场景脱节 |
| 包内图片集中 | `banner-1.jpg` 116K，占静态资源 91% | 新增插图几乎没有预算 |
| 缺少页面壳 | 每页自己处理背景、底栏占位、安全区 | 新页面容易漏安全区/底栏 |
| 图标语义弱 | 大量 `t-icon` 直接写 rgba 颜色 | 选中态/品牌态不统一 |

### 1.4 现有优势（必须保留）

- 功能开关与审核模式完整：`feat()` / `auditMode()` 逐页门控，服务端 403 兜底。
- 网络层健壮：重试、CSRF 自愈、冷启动本地快照。
- 页面职责清晰，逻辑没有和 TDesign 深度耦合，适合做视觉层替换。
- 列表分页、下拉刷新、图片预览、评论楼中楼等基础能力已经具备。
- 包体控制在 874K，`lazyCodeLoading: requiredComponents` 已开启。

### 1.5 升级约束

1. **不改后端契约。** 所有新 UI 只消费现有 `/mp/*` 数据：`posts`、`postDetail`、`categories`、`tags`、`micro`、`me`、`config`。
2. **微信包内图片总量 < 200K。** 当前 124K，升级后目标 ≤ 180K。
3. **TDesign 样式隔离。** 自定义组件内样式不能靠页面选择器穿透；要么用 CSS 变量，要么用 `t-class-*` 外部类。
4. **自定义导航要处理状态栏和胶囊。** 必须用 `uni.getWindowInfo()` + `uni.getMenuButtonBoundingClientRect()`，并对旧机型做兜底。
5. **无原生 tabBar。** 继续用 `reLaunch` 切换，自定义底栏必须自己处理安全区和页面占位。
6. **审核模式不能被视觉升级破坏。** 登录/评论/点赞/收藏的隐藏逻辑要继续逐页生效。
7. **不引入广告、积分、邀请、付费资源。** 与个人博客定位和审核策略不符。

## 2. 参考项目研究

### 2.1 项目定位与技术

`yimo-resource-blog` 是 UniApp + Vue2 + ColorUI + uView 的资源下载博客，核心是「文章 + 资源 + 壁纸/头像 + 去水印 + 积分兑换 + 流量主广告」。它有 4 个原生 Tab：首页、探索、宝库、我的；后端不在仓库内。

它的视觉不是“设计系统驱动”，而是“模块拼装驱动”：每个页面有独立的头图、卡片、图标和间距，整体靠统一的插画语言和圆角白卡维持一致性。

### 2.2 15 张截图的设计拆解

| 模块 | 参考站做法 | 效果 | 对纸鱼的启发 |
| --- | --- | --- | --- |
| 首页顶部 | 全宽天空/插画背景，内容区上浮覆盖 | 第一眼有品牌氛围 | 首页需要“头图 + 上浮内容”的层次，而不是直接列表 |
| 公告 | 小喇叭图标 + 横向跑马灯 | 运营感强 | 纸鱼可做“站点公告/更新”细条，但默认不显示，避免噪音 |
| 横幅 | 大圆角轮播图，圆点指示 | 视觉锚点 | 保留轮播能力，但默认只展示一张精选，减少无效自动播放 |
| 快捷入口 | 4 宫格，手绘插画图标 + 文字 | 亲切、易扫 | 我的页/发现页可用四宫格，但图标要统一线性风格 |
| 文章列表 | 左图右文白卡，标题两行 + 时间/浏览量 | 信息密度适中 | 纸鱼采用“左文右图 + 无图变体”，并增加摘要与分类 |
| 分区标题 | 图标 + 标题 + “查看更多” | 分区清晰 | 统一为 `zz-section-head`，带小图标和右侧动作 |
| 分类标签 | 多种 pastel 胶囊，颜色区分分类 | 活泼、易识别 | 采用受控的 6 色分类色板，确定性映射，不随机 |
| 底部导航 | 自定义线性图标（房子/指南针/星星/小熊），选中变蓝 | 品牌记忆强 | 纸鱼重做自定义 4 Tab，图标统一线条 + 选中态动效 |
| 搜索页 | 星空大图 + 文案 + 胶囊搜索框 + 彩色标签 + 热门文章 | 工具页也有情绪 | 发现页做“搜索 + 热词 + 分类 + 推荐”，但头图用纸感渐变而非实拍 |
| 我的页 | 全幅照片头图 + 积分黑卡 + 关注/联系双卡 + 四宫格 + 图标列表 | 个人页有运营感 | 纸鱼做“个人头图 + 数据卡 + 四宫格 + 菜单”，去掉积分/广告 |
| 资源列表 | 双列资源卡，底部“获取详情”按钮 | 图片优先、转化明确 | 纸鱼文章以文字为主，不采用双列资源卡；收藏/历史可用缩略图列表 |
| 详情页 | 大图头图 + 标题 + 黄底说明 + 正文 + 固定底部操作栏 | 阅读和转化兼顾 | 详情页采用沉浸头图 + 固定操作栏 + 评论，但不放广告按钮 |
| 空态/加载 | 插画 + 文案 + 加载 GIF | 有温度 | 用 3–4 张轻量插图 + 文案，不用 GIF（包体不友好） |
| 文案 | 口语化、带表情符号 | 亲切但不够克制 | 纸鱼保留温度，减少表情符号，形成“编辑手记”语气 |

### 2.3 可借鉴清单

- **顶部沉浸感**：头图/渐变 + 内容上浮，建立第一屏品牌记忆。
- **卡片节奏**：白卡、圆角、轻阴影、统一间距，形成可预期的浏览节奏。
- **图标语言**：同一套线性图标 + 少量手绘插图，不要在页面里混用 emoji、实拍图标和彩色 3D 图标。
- **自定义底栏**：底栏是品牌露出最便宜的位置。
- **发现页**：搜索不只是工具，可以是内容发现入口。
- **我的页分区**：个人头图、数据、快捷入口、菜单四层，比纯列表更有留存感。
- **分区标题**：图标 + 标题 + “查看更多”，比裸文字标题更有仪式感。

### 2.4 不借鉴清单

- 信息流中插入广告卡、固定广告栏、激励视频按钮。
- 积分、任务、邀请、抽奖等运营模块。
- 拼贴式文章封面、低质量实拍图、GIF 加载图。
- 大量内联样式、`upx`/`rpx` 混用、绝对定位搭页面。
- 低对比度灰字、过小字号、固定底栏遮挡正文。
- 高饱和 pastel 色铺满全屏；纸鱼需要更克制的色彩比例（纸底 80% / 白卡 15% / 强调色 5%）。

### 2.5 结论

参考站真正值得学的是**结构**：第一屏身份、卡片节奏、图标系统、底栏、发现页、个人页。  
纸鱼要替换的是**皮肤**：把“资源站的热闹”换成“个人博客的纸感与编辑感”。

## 3. 设计方向

### 3.1 品牌概念：「纸鱼手帐」

> 一张有温度的纸，一条在海边游动的鱼。  
> 纸负责阅读，鱼负责记忆。

- **纸**：暖白纸底、细线、书页式留白、印章式标签。
- **鱼**：鱼蓝主色、波纹/涟漪、少量手绘鱼作为引导和空态角色。
- **手帐**：编辑式标题、日期戳、分类色签、阅读进度、结尾“完”字。

### 3.2 三套方向对比

| 方向 | 关键词 | 优点 | 风险 | 适用 |
| --- | --- | --- | --- | --- |
| **A. 纸鱼手帐（推荐）** | 暖纸、鱼蓝、珊瑚、手绘线稿 | 有品牌辨识度；适合长文阅读；不挑内容 | 需要克制用色，避免“文艺过头” | 个人博客、技术/生活混合内容 |
| B. 海盐气泡 | 天蓝、纯白、pastel、插画 | 更接近参考站，年轻活泼 | 容易同质化；长时间阅读略跳 | 想强化“轻松内容社区”气质 |
| C. 墨夜杂志 | 深墨、米白、金属色、衬线 | 高级、编辑感强 | 深色列表压情绪；小程序暗色适配成本高 | 设计/摄影类内容为主 |

**推荐 A。** 理由：纸鱼的内容是技术、建站、生活、随笔、设计混合，A 的包容性最好；同时“纸 + 鱼”能直接承接品牌名，不需要额外解释。

### 3.3 设计原则

1. **阅读优先。** 任何装饰都不能挤压正文；详情页正文行高 ≥ 1.8，字号 ≥ 32rpx。
2. **纸感层次，不靠重阴影。** 用底色差、细线、圆角、轻微投影建立层次，避免“每个卡片都浮起来”。
3. **一个强调色。** 鱼蓝负责品牌/链接/选中，珊瑚只负责点赞、收藏、重要 CTA；不同时出现第三种高饱和色。
4. **图标统一。** 全站线性图标；选中态用填充变体；插图只出现在空态/欢迎/结尾。
5. **动效有目的。** 只做按压、切换、点赞、进度四类反馈；不做无意义的循环动画。
6. **内容密度可控。** 首页一屏至少露出 2.5 篇文章；详情页一屏以正文为主，不堆模块。

### 3.4 语气与文案

- 关键词：温和、简洁、有编辑感；可以有一个“鱼”的隐喻，但不堆谐音梗。
- 示例：
  - 空首页：「鱼塘还很安静，等第一篇文章落下来」
  - 空收藏：「收藏夹空空的，遇到喜欢的文章就收进来」
  - 空历史：「还没有足迹，去纸鱼逛逛」
  - 空评论：「还没有评论，来坐第一排」
  - 加载更多：「正在捞更多…」
  - 到底：「— 游到水底了 —」
  - 网络错误：「网络好像走丢了，点一下重新找鱼」
  - 登录：「登录后，把喜欢的内容留在鱼塘里」
- 审核模式下所有文案退化为中性表述，不使用“鱼塘/捞”等可能让审核误判的运营词。

### 4.2 字体与排版

小程序不引入外部字体（包体和加载稳定性都不划算），使用系统字体：

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

| 层级 | 字号 | 行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| Display | 52rpx | 1.3 | 700 | 首页品牌字、空态大标题 |
| H1 | 44rpx | 1.45 | 700 | 文章标题 |
| H2 | 36rpx | 1.4 | 600 | 页面标题、分区大标题 |
| H3 | 32rpx | 1.45 | 600 | 卡片标题、评论数 |
| Body | 30rpx | 1.85 | 400 | 文章正文 |
| UI Body | 28rpx | 1.6 | 400 | 列表、表单、菜单 |
| Caption | 24rpx | 1.5 | 400 | 摘要、辅助说明 |
| Meta | 22rpx | 1.4 | 400 | 时间、浏览量、标签 |
| Micro | 20rpx | 1.3 | 500 | 徽章、角标 |

规则：

- 数字使用 `font-variant-numeric: tabular-nums;`，统计数字不跳动。
- 标题最多 2 行，正文摘要最多 2 行；一律用 `-webkit-line-clamp`。
- 中英混排时行高略增；文章正文 `letter-spacing: 0.2rpx`。
- 不使用 300 以下字重；小程序低端机渲染细字发虚。

### 4.3 间距、圆角、阴影

| 类别 | 值 | 用法 |
| --- | --- | --- |
| 基础单位 | 8rpx | 所有间距取 4 的倍数 |
| 页面边距 | 32rpx | 左右统一 |
| 卡片内边距 | 28–32rpx | 大卡 32rpx，小卡 24rpx |
| 卡片间距 | 20rpx | 列表卡之间 |
| 区块间距 | 48rpx | 分区之间 |
| 卡片圆角 | 24rpx | 文章卡、菜单卡、评论卡 |
| 头图圆角 | 32rpx | 首页/详情头图 |
| 缩略图圆角 | 16rpx | 文章封面、历史缩略图 |
| 胶囊 | 999rpx | 分类、标签、搜索框 |
| 描边 | 1rpx `--zz-line` | 卡片/分割线 |
| 轻阴影 | `0 8rpx 24rpx rgba(30, 42, 50, 0.06)` | 浮起卡片 |
| 极轻阴影 | `0 2rpx 8rpx rgba(30, 42, 50, 0.04)` | 普通卡片 |

原则：**一屏最多两层阴影**；列表卡优先用描边 + 极轻阴影，头图/弹层才用轻阴影。

### 4.4 图标与插图

**图标**

- 统一使用 `t-icon` 线性图标；选中态用 `-filled` 变体。
- 默认尺寸：导航 40rpx、列表 40rpx、操作栏 44rpx、徽章 24rpx。
- 颜色只取 token：`C.ink2` / `C.ink3` / `C.brand` / `C.accent`。
- 不混用 emoji、彩色 3D 图标、实拍图标。

**插图**

- 只用于空态、网络错误、登录欢迎、文章结尾，不铺满页面。
- 风格：单色线稿 + 1–2 个色块（鱼蓝/珊瑚/薄荷），纸面留白。
- 预算：3 张核心插图（空态、离线、欢迎）+ 图标组合变体；单张 ≤ 12K，总量 ≤ 40K。
- 优先 PNG8/JPEG；WebP 需在目标基础库验证后再用。插图加载失败时回退为 `t-icon` + 色块。

**无封面文章占位**

- 使用分类色板的浅底 + 大号线性图标 + 分类名小字；不再用统一灰块。
- 同一分类全站同色，形成内容识别。

### 4.5 动效

| 场景 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| 按压缩放 | 120ms | `ease-out` | `scale(0.98)`，卡片/按钮 |
| Tab 切换 | 180ms | `cubic-bezier(.2,.8,.2,1)` | 图标上移 4rpx + 放大 1.08 |
| 点赞 | 240ms | `cubic-bezier(.2,.8,.2,1)` | 图标弹一下 + 数字变化 + 轻震动 |
| 页面进入 | 260ms | `cubic-bezier(.2,.8,.2,1)` | 首屏内容 `translateY(16rpx)` + 淡入 |
| 骨架脉冲 | 1400ms | `ease-in-out` | 透明度 0.5–0.9 循环 |
| 阅读进度 | 跟随滚动 | 无 | `transform: scaleX()`，不触发布局 |

约束：

- 不使用无限旋转/漂浮动画（除骨架）。
- 低端机上减少同时动画数量；列表项不做逐个入场。
- 尊重系统“减少动态效果”设置（如基础库支持 `prefers-reduced-motion`，则关闭入场和脉冲）。

### 4.6 可访问性

- 正文与背景对比度 ≥ 4.5:1；大字号/图标 ≥ 3:1。
- 可点击区域 ≥ 88rpx × 88rpx；图标按钮加透明热区。
- 所有图标按钮加 `aria-label`；图片加 `alt`（mp-html 图片由内容提供）。
- 支持系统字体放大：不使用固定高度裁切文字；标题最多 2 行，超出省略。
- 错误提示不只靠颜色，配文字/图标。
- 点赞/收藏状态同时用图标形状 + 颜色表达。

### 4.7 暗色模式（P2，不进首版）

- 首版不做全站暗色，避免 TDesign light 主题、原生导航、状态栏和审核成本。
- token 化后可在 P2 增加 `theme.json` + `@media (prefers-color-scheme: dark)`：
  - 纸底 → `#12181C`，卡片 → `#1B2328`，主文本 → `#F2EFE8`，品牌 → `#6FB6CC`。
- 首版需保证系统暗色模式下不出现“白底白字/黑底黑字”的硬伤；原生导航颜色跟随 `pages.json` 的浅色配置。

## 6. 页面设计

### 6.1 全局框架

**页面壳**

- 页面底色统一 `--zz-paper`；卡片 `--zz-card`。
- 内容左右边距 32rpx；Tab 页底部预留 `112rpx + safe-area`。
- 所有页面使用统一类名：`.zz-page`、`.zz-gutter`、`.zz-safe-bottom`。
- 原生导航页在 `pages.json` 设置 `navigationBarBackgroundColor: "#F7F4EE"`、`backgroundColor: "#F7F4EE"`、`backgroundTextStyle: "dark"`。

**自定义导航**

- 高度：`statusBarHeight + 44px`。
- 左侧：返回（二级页）或品牌字（Tab 页）。
- 中间：页面标题（Tab 页可隐藏，用品牌字替代）。
- 右侧：搜索/设置等动作，放在胶囊左侧安全区内。
- 模式：`transparent`（头图上）与 `solid`（纸白底 + 细线）。
- 首页/微语/发现/我的使用浅色纸底导航，状态栏文字黑色；详情页头图使用深色遮罩 + 白色图标，滚动后切换为纸白导航（`uni.setNavigationBarColor`）。

**自定义底栏**

- 高度 112rpx + `env(safe-area-inset-bottom)`。
- 背景 `rgba(255,255,255,0.98)`，顶部 1rpx 细线。
- 4 个 Tab：图标 44rpx + 文字 20rpx；选中态鱼蓝 + 图标上移 4rpx + 6rpx 圆点。
- 切换用 `uni.reLaunch`；当前 Tab 不重复跳转。
- 页面底部放同高占位，避免内容被遮挡。

### 6.2 首页

**目标**：第一屏建立“纸鱼”的品牌感；第二屏开始高效浏览文章。

**结构**

```
┌──────────────────────────────────┐
│ 状态栏                            │
│ 纸鱼 · 记录与分享        ⌕   ●●  │ 自定义导航

│ │ 摘要一行                      │ │ 封面 + 渐变遮罩
│ │ 作者 · 日期 · 约 6 分钟       │ │
│ └──────────────────────────────┘ │
│                                  │
│ [全部] [技术] [建站] [生活] [设计] → │ 分类胶囊
│                                  │
│ 最新文章                  12 篇 › │ 分区标题
│ ┌──────────────────────────────┐ │
│ │ 标题两行              [封面]  │ │ 标准卡
│ │ 摘要两行                     │ │
│ │ 分类 · 3 天前 · 1.2k 阅读     │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 无封面文章                    │ │ 文字卡
│ │ 摘要两行                     │ │

└──────────────────────────────────┘
```

**模块规格**

1. **品牌导航**
   - 左侧：「纸鱼」28rpx 600，字距 2rpx；下方小字「记录与分享」18rpx `ink-3`（可选）。
   - 右侧：搜索图标 40rpx；胶囊按钮区域留白。
   - 滚动 > 80rpx 后加纸白底 + 细线；品牌字保持可见。

2. **编辑精选头图**
   - 高度 560rpx，左右 32rpx，圆角 32rpx。
   - 数据优先级：`state.banners` 配置图 > 首篇带封面文章 > 首篇文章（无封面用分类色块）。
   - 有封面：`image mode=aspectFill` + 底部 60% 黑色渐变遮罩 + 白色标题。
   - 无封面：分类浅底 + 大号线性图标 + 纸纹渐变；标题用墨色。
   - 内容：分类胶囊（半透明白底/分类色）、标题 2 行 40rpx、摘要 1 行 24rpx、作者/日期/阅读时长 22rpx。
   - 多张 banner：原生 `swiper` + 自定义圆点（当前页鱼蓝，其他白 40%）；只有一张时静态展示，不自动播放。
   - 点击：有 `slug` 进详情；无 `slug` 不响应（避免死链）。

3. **分类胶囊**
   - 横向滚动；高 64rpx；左右 24rpx；圆角 999rpx。
   - 未选中：白底 + `--zz-line` 描边 + `ink-2`；选中：分类色浅底 + 分类深字 + 600 字重。
   - 「全部」固定第一位；分类超过 8 个时横向滚动，不换行。
   - 切换分类时：列表回到顶部、显示骨架、清空旧数据。

4. **分区标题**
   - 左侧：小图标（书本/时钟/火苗）+ 标题 32rpx 600。
   - 右侧：「12 篇」或「查看更多 ›」24rpx `ink-3`。
   - 下方 20rpx 间距。

5. **文章卡（三种变体）**
   - **标准卡**：白卡 24rpx 圆角，内边距 28rpx；左侧标题 30rpx 600（2 行）+ 摘要 24rpx `ink-2`（2 行）+ meta；右侧 176rpx 方图 16rpx 圆角。
   - **文字卡**：无封面；左侧加 6rpx 分类色竖条；标题 + 摘要 + meta；右侧留白或小图标。
   - **精选卡**：头图 320rpx 全宽 + 标题/摘要/ meta；只用于列表第一项（如果头图没有占用）。
   - 置顶：标题前小金标「置顶」，不使用大色块。
   - 分类：用分类色小字，不用下划线。
   - 阅读数：`browse` 图标 24rpx + 数字；时间用 `fmtRel`/`fmtShort`。
   - 按压：整卡 `scale(0.99)` + 极浅底色，120ms。

6. **加载/空/错误**
   - 首屏骨架：1 张头图块 + 3 张文章卡块，尺寸与真实卡一致。
   - 空：`zz-empty` 空态插图 + 「鱼塘还很安静」+ 「去写点什么」？没有发布能力，改为「去逛逛微语」按钮。
   - 错误：「网络好像走丢了」+ 重试按钮。
   - 到底：「— 游到水底了 —」22rpx `ink-4`。

7. **下拉刷新**
   - 背景色 `#F7F4EE`，`backgroundTextStyle: dark`；刷新完成 `toast('已刷新')` 可选，不强制。

### 6.3 微语

**目标**：把“列表”做成“时间流”，让短内容有呼吸感。

**结构**

### 6.10 空态 / 错误 / 骨架 / 分享

**空态组件 `zz-empty`**

| 类型 | 插图/图标 | 标题 | 说明 | 动作 |
| --- | --- | --- | --- | --- |
| `articles` | 纸船小鱼 | 鱼塘还很安静 | 等第一篇文章落下来 | 去微语看看 |
| `comments` | 对话气泡 | 还没有评论 | 来坐第一排 | 写评论 |
| `favorites` | 星星罐子 | 收藏夹空空的 | 遇到喜欢的文章就收进来 | 去逛逛 |
| `history` | 时钟波纹 | 还没有足迹 | 去纸鱼逛逛 | 回首页 |

| `offline` | 雨伞鱼 | 网络好像走丢了 | 检查网络后重试 | 重新加载 |
| `closed` | 关门的纸屋 | 功能已关闭 | 该功能暂未开放 | 回首页 |
| `notfound` | 空纸页 | 文章不存在 | 可能已下架或被移动 | 回首页 |

- 插图尺寸 280–320rpx；标题 32rpx 600；说明 24rpx `ink-3`；动作按钮鱼蓝文字/描边。

**骨架 `zz-skeleton`**

- 变体：`post-card`（176rpx 方图 + 3 行）、`post-detail`（600rpx 头图 + 标题 + 4 行）、`comment`（头像 + 3 行）、`profile`（128rpx 圆 + 2 行）。
- 颜色：`--zz-paper-deep` 底 + 白色高光；脉冲 1.4s；不使用闪光扫过（低端机更稳）。
- 尺寸必须与真实内容一致，避免骨架到内容的跳动。

**分享**

- 首版：`onShareAppMessage` 使用文章封面；无封面用品牌分享图（5:4，≤20K）。
- 分享图内容：纸底 + 纸鱼字标 + 「记录与分享」+ 一条鱼线稿；不放二维码/个人信息。
- P2：Canvas 生成动态分享卡（封面 + 标题 + 站点名），失败回退静态图。

组件 API 原则：

- 只暴露语义化 props（`variant`、`size`、`active`、`disabled`），不暴露颜色值。
- 颜色/间距全部从 token 读取；组件内不写品牌 hex。
- 事件名避开原生 `tap`（现有 `select` 约定继续保留），防止双触发。
- 所有可点击组件提供 `hover-class` 或 `:active` 反馈；小程序组件样式隔离时在组件内声明按压类。

## 8. 技术实现

### 8.1 token 落地

新增：

```
src/styles/tokens.css      # 颜色、间距、圆角、阴影 CSS 变量
src/styles/base.css        # page 基础样式、通用类
src/common/design.js       # JS 颜色/分类色板（供 t-icon:color 使用）
```

- `App.vue` 的 `<style>` 改为 `@import './styles/tokens.css'; @import './styles/base.css';`。
- 删除 `App.vue` 中旧 `--zz-*` 定义；保留 `page` 基础字体/背景。
- `src/common/theme.js` 扩展：
  - `C`：品牌/文本/强调色常量。
  - `categoryStyle(slug)`：返回 `{ bg, fg, icon, gradient }`。
  - 保留 `coverStyle`、`usableCover`、`avatarChar`，内部改用新色板。
- 全局替换 47 处硬编码颜色：
  - `#0052d9` → `C.brand` 或 `var(--zz-brand)`。
  - `rgba(0,0,0,.4/.6/.9)` → `C.ink3/ink2/ink`。
  - `mdcss.js` 的 `BRAND`、灰阶 → token 常量。

### 8.2 自定义导航 `zz-navbar`

实现要点：

```js
const win = uni.getWindowInfo ? uni.getWindowInfo() : uni.getSystemInfoSync()
const menu = uni.getMenuButtonBoundingClientRect()
const statusBarHeight = win.statusBarHeight || 20
const navBarHeight = menu && menu.top
  ? (menu.top - statusBarHeight) * 2 + menu.height
  : 44
const capsuleInset = win.windowWidth - menu.left + 8
```

- Props：`title`、`back`、`transparent`、`scrollTop`、`showSearch`、`showSettings`。
- 结构：固定定位容器 + 状态栏占位 + 导航行；标题绝对居中，左右动作避开胶囊。
- 透明模式：背景透明 + 顶部深色/浅色渐变（根据页面）；实底模式：`--zz-paper` + 1rpx 底边。
- 返回：`uni.navigateBack()`；无栈时 `uni.reLaunch({ url: '/pages/index/index' })`。
- 状态栏文字：
  - 浅色页面：`pages.json` 设 `navigationBarTextStyle: "black"`。
  - 详情头图：页面 `onLoad` 调 `uni.setNavigationBarColor({ frontColor: '#ffffff', backgroundColor: '#000000' })`；滚动过阈值切回黑色；`onUnload` 恢复。若低版本不支持，使用白色图标 + 深色渐变兜底。
- 滚动监听：页面 `onPageScroll` 只更新 `scrollTop`；导航内部用 `computed` 判断阈值，避免每帧 setData。

### 8.3 自定义底栏 `zz-tabbar`

- 改为纯 `view` 实现，不再用 `t-tab-bar`。
- 数据：

```js
const tabs = [
  { key: 'home', label: '文章', icon: 'home', path: '/pages/index/index' },
  { key: 'micro', label: '微语', icon: 'chat', path: '/pages/micro/index' },
  { key: 'discover', label: '发现', icon: 'search', path: '/pages/search/index' },
  { key: 'mine', label: '我的', icon: 'user', path: '/pages/mine/index' },
]
```

- 若 `t-icon` 没有合适的「发现」图标，用 `earth`/`app`/`search` 替代，实施时以图标表为准。
- 选中态：图标 `translateY(-4rpx) scale(1.08)`，颜色 `--zz-brand`；下方 6rpx 圆点或 32rpx 胶囊底。
- 点击：同 key 不处理；否则 `uni.reLaunch`。
- 动态项：`feat('micro')` / `feat('search')` 为 false 时隐藏对应 Tab；保持剩余项等分。
- 占位：组件内输出一个同高 holder，页面无需再写。
- 页面切换会重建页面，这是现有行为；保持简单，不做 keep-alive。

### 8.4 TDesign 边界

保留：

- `t-icon`：全站图标。
- `t-popup`：登录面板。
- `t-loading`（如需要）：列表加载。

替换/移除：

- `t-tab-bar` → `zz-tabbar`。
- `t-empty` → `zz-empty`。
- `t-skeleton` → `zz-skeleton`。
- `t-search` → `zz-search-bar`。
- `t-swiper` → 原生 `swiper` + 自定义圆点。
- `t-tag` → `zz-chip`。

原因：这些组件的默认视觉/样式隔离与品牌冲突，替换后页面样式更可控，也能减少 TDesign 组件体积。

### 8.5 正文样式 `mdcss.js`

- 改为从 `design.js` 读取颜色，禁止硬编码。
- 新的样式映射：

| 元素 | 新样式 |
| --- | --- |
| `p` | `margin: 0 0 28rpx` |
| `h1` | 44rpx / 700 / 上 48rpx 下 20rpx |
| `h2` | 36rpx / 700 / 左侧 6rpx 鱼蓝竖条 / 上 48rpx 下 20rpx |
| `h3` | 32rpx / 600 / 上 40rpx 下 16rpx |
| `blockquote` | 鱼蓝浅底 + 左 6rpx 鱼蓝边 + 20rpx 24rpx 内边距 + 0 16rpx 16rpx 0 圆角 |
| `code` | 纸深底 + 珊瑚深字 + 8rpx 圆角 + 2rpx 10rpx 内边距 |
| `pre` | 墨色底 + 纸色字 + 16rpx 圆角 + 24rpx 内边距 + 横向滚动 |
| `a` | 鱼蓝 + 下划线 |
| `img` | 100% + 16rpx 圆角 + 24rpx 上下 |
| `table` | 100% + `table-layout: fixed` + 24rpx |

- 阅读时长：`Math.max(1, Math.round(textLength / 400))` 分钟；从 `contentHtml` 去标签后计算。

### 8.6 资源与包体预算

| 资源 | 现状 | 目标 | 处理 |
| --- | --- | --- | --- |
| `banner-1.jpg` | 116K | 0–20K | 默认头图改 CSS 渐变；远程 banner 由插件配置下发 |

策略：

### 8.7 性能

- 首屏：首页只请求 `posts` + `categories`；banner 复用第一页数据，不额外请求。
- 列表：分页 10 条；图片 `lazy-load`；卡片图片固定宽高，避免布局跳动。
- 滚动：`onPageScroll` 节流 50ms；进度条用 `transform: scaleX()`；导航状态只在阈值变化时更新。
- 动画：列表项不做逐个入场；阴影只用于头图/浮层；低端机减少同时动画。
- 组件：替换重型 TDesign 组件；`mp-html` 仍只在详情页引入。
- 包体：`lazyCodeLoading: requiredComponents` 保持；移除未使用的 TDesign 组件引用。
- 目标：中端安卓 4G 首屏 <1.5s；滚动无明显掉帧；详情页 TTI <2.5s。

### 8.8 兼容性

- iOS/Android 微信；基础库最低版本按项目当前配置（不新增高版本 API）。
- 小屏（iPhone SE 375×667）与大屏（Pro Max / 折叠屏）都要验证：头图高度、标题截断、底栏安全区、胶囊避让。
- 自定义导航必须测试：
  - 刘海屏/灵动岛；
  - 安卓状态栏高度差异；
  - 胶囊按钮位置差异；
  - 页面滚动时状态栏文字颜色切换。
- 图片：`image` 加载失败要有占位；`svg` 不作为封面（现有约束保留）。
- 远程图片：域名白名单、HTTPS、失败回退。

## 11. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 自定义导航与胶囊错位 | 头部遮挡/难看的空白 | 用 `getMenuButtonBoundingClientRect`；小屏/刘海/安卓三组真机验证；提供 44px 兜底 |

| TDesign 样式隔离 | 组件内部改不动 | 用 CSS 变量 + `t-class-*`；强视觉组件直接替换为 `zz-*` |

| 设计稿与实现偏差 | 越做越像“另一个 TDesign” | token 单一来源；组件 API 冻结；每页截图对比；禁止页面硬编码颜色 |
