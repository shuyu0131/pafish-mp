## 0. 为什么推翻 V1 的「纸鱼手帐」

V1 的问题是：它是我对“纸鱼”这个名字的再创作，不是对参考站设计的拆解。

- 米色纸底、墨绿主色、珊瑚强调，整体偏“设计系统展板”，不是参考站那种轻快的消费级内容产品。
- 大量英文小标签（EDITOR'S PICK / CURRENT THEME / TYPE SCALE）、点阵背景、右侧规格面板，让界面像给设计师看的 sample，而不是给用户用的 App。
- 插画缺位，靠渐变和 Lucide 线性图标撑场面，缺少参考站最关键的“手绘插画 + 照片头图”的视觉密度。
- 参考站真正的辨识度来自：**天空蓝底图、手绘彩色插画、白卡、照片头图、彩色胶囊、厚描边底栏图标、黑金个人卡**。V1 一样都没抓住。

V2 的目标不是“更高级”，而是**更像参考站那套内容产品的视觉语言**，同时保留纸鱼自己的内容和品牌。

## 1. 参考站设计拆解（源码级）

### 1.1 首页

- 顶部是一张 1080×700 的天空插画 `static/imgs/index_bj.jpg`：浅蓝底、白云、星星、小树，中间留白给内容。
- 内容区 `margin-top: -370rpx` 上浮，压在天空图上。
- 公告条：白色圆角条 + 小喇叭图标 + 横向跑马灯。
- 大横幅：大圆角图片，圆点指示；图片来自后台配置。
- 4 宫格：白卡，4 个 400×400 手绘插画图标（资源库、手机壁纸、电脑壁纸、视频资源、水印去除等），下面 30upx 黑字。
- 分区标题：小图标 + 30upx 标题 + 右侧“查看更多”。
- 文章卡：白卡、18rpx 圆角，左图 43% 宽、200rpx 高，右侧标题两行、时间 + 浏览量。
- 页面底：`#F7F7F7`；卡片纯白；阴影极轻。

### 1.2 底栏

- 原生 `tabBar`，选中色 **`#60C2FF`**。
- 图标是 40×40 左右的自绘 PNG：未选中是灰蓝 `#A8B4C8` 粗描边空心；选中是 `#60C2FF` 填充 + 深灰描边。
- 图标分别为：房子、指南针（带轨迹）、星星、小熊。风格厚描边、圆角、略带手绘感。

### 1.3 发现 / 搜索

- 深蓝星空头图，白色标题“悬悬而望”，一句 slogan，下面白色胶囊搜索框。
- 彩色胶囊标签：粉、青、紫、黑、绿等，直接对应分类。
- 热门文章列表：左图右文白卡。

### 1.4 我的

- 全幅风景照片头图，头像 + 昵称直接压在照片上。
- 黑色积分卡：黑底、金色数字/按钮，强对比，压在头图下缘。
- 两张白色服务卡：关注我们 / 联系我们，彩色图标。
- 四宫格：白卡、彩色线性图标、文字。
- 白色列表：SVG 图标 + 标题 + 右侧箭头。
- 底部免责声明小字。

### 1.5 文章详情

- 大图头图（500upx），左上返回/主页按钮。
- 标题 42upx 加粗，时间 24upx 灰色。
- 黄色说明卡：浅黄底、橙色文字，提示“观看广告获取内容”。
- 正文 rich-text；推荐阅读左图右文。
- 固定底部操作栏：点赞 / 资源下载 / 分享，彩色图标 + 灰色文字。

### 1.6 色彩与组件

- ColorUI 调色板（浅色版）：
  - 红 `#E54D42` / `#FADBD9`
  - 橙 `#F37B1D` / `#FDE6D2`
  - 绿 `#39B54A` / `#D7F0DB`
  - 青 `#1CBBB4` / `#D2F1F0`
  - 蓝 `#0081FF` / `#CCE6FF`
  - 紫 `#6739B6` / `#E1D7F0`
  - 粉 `#E03997` / `#F9D7EA`
  - 灰 `#8799A3` / `#E7EBED`
  - 黑 `#333333`
- 卡片圆角：15–30rpx；页面底 `#F5F5F5` / `#F7F7F7`；白卡不描边或极浅描边。
- 字号：标题 30–42upx，正文 26–34upx，meta 20–22upx；整体比 V1 更大、更直接。
- 阴影：几乎不用；层次靠白卡与浅灰底。

### 1.7 参考站不值得照搬的部分

- 信息流广告、固定广告栏、激励视频。
- 积分、任务、邀请、抽奖。
- 拼贴封面、低质量实拍图、GIF 加载图。
- 内联样式、`upx`/`rpx` 混用、绝对定位搭页面。
- 低对比度灰字和过小字号。

## 2. V2 设计方向：「海盐天空 · 内容卡片」

### 2.1 一句话

**天空蓝底图 + 手绘彩色插画 + 白色内容卡 + 照片头图 + 厚描边底栏**。  
这是参考站真正有效的视觉配方，换成纸鱼的内容和品牌即可。

### 2.2 与 V1 的差别

| 维度 | V1 纸鱼手帐 | V2 海盐天空 |
| --- | --- | --- |
| 页面底 | 暖纸 `#F7F4EE` | 冷白灰 `#F5F7FA` |
| 主色 | 墨绿 `#1F6F8B` | 天空蓝 `#60C2FF` |
| 强调 | 珊瑚 `#E86A4A` | 橙 `#F37B1D` + 金 `#F6C445` |
| 头图 | 渐变/纸纹 | 天空插画 + 照片 |
| 图标 | Lucide 单色线性 | 400×400 手绘彩色插画 + 厚描边底栏 PNG |
| 卡片 | 纸感、细描边 | 纯白、18rpx 自然圆角、极轻阴影 |
| 标签 | 分类圆点 | ColorUI 彩色胶囊 |
| 个人页 | 纸感身份卡 | 照片头图 + 头部数据带 |
| 底栏 | TDesign 图标 | 自绘 PNG 图标 |
| 语气 | 文艺、克制 | 轻快、直接、内容优先 |

### 2.3 设计原则

1. **先有图，再有字。** 首页、发现、我的、详情都要有一个“图”的锚点：天空图、浅蓝插画、照片、手绘插画。
2. **白卡是主角。** 页面底浅灰，内容全部落在白卡里；卡片之间用 8–10px 间距。
3. **彩色只出现在该出现的地方。** 插画、分类胶囊、图标；金色只用于收藏星标/收藏态，置顶用浅绿小胶囊，正文和标题保持黑灰。
4. **字号适中，标题不压得过轻。** 分区标题 16px/600，文章卡标题 17px/500，摘要 13px/400，卡片底部 11.5px/500；不要用 8px 英文小标签。
5. **底栏是品牌记忆点。** 直接使用厚描边、填充色的手绘图标；不要用细线 Lucide。
6. **不复制参考站的商业化模块。** 广告、积分、邀请、抽奖全部不做。
7. **圆角自然，不刻意。** 大卡片 9px（18rpx）、头图/横幅 14px、图片 8px；不要把所有东西做成 20px 大圆角，也不要为了“去圆角”改成 0。
8. **零 CSS 渐变。** 按钮、头像、深色底带、引用卡、页面背景一律纯色；照片上压字用纯色遮罩，不用渐变。
9. **零 emoji。** 所有图形用手绘 PNG 或线性图标；不要用 emoji 充当图标、徽章或装饰。

## 4. 页面视觉规格

### 4.1 首页

```
完整天空插画首屏（nav + 插画，背景轻微虚化，无文字）
├─ 搜索条：压在插画下缘的玻璃胶囊输入框，确认后首页内展示结果
├─ 公告卡：图标 + 橙色「公告」标签 + 单行文本 + 全部
├─ 四宫格白卡：最多 4 个分类，固定 4 列
├─ 分区标题：book 图标 + 最新文章 + 篇数 >
├─ 文章卡：标题/摘要 + 右上封面 + 底部标签/浏览/点赞
└─ 到底啦
```

- 天空图优先级：后台配置图 > 本地 `sky-bg.png` 品牌插画 > 纯色天空兜底（不用渐变）。
- 封面规则：文章优先 `coverUrl / cover / image / thumbnail`；缺省不显示文章封面（不再用分类插画充当封面）；分类宫格/分类卡才回退 `cat-*.png`。相对路径按 `BASE_URL` 补全，SVG 封面不渲染。
- 公告卡：读取 `/mp/config.notice` 或 `/mp/config.notices`（兼容旧 `banners` 条目的 `title/text`），白色大卡、站内橙色「公告」标签、单行文本和「全部」；多条点击轮换，不再用跑马灯，也不再展示轮播图。
- 顶部插画按无轮播重新构图：1080×800 竖向场景（纸船、跃鱼、纸飞机、云和太阳），导出 780×578，首屏高度 556rpx；云/太阳/远景做轻微景深虚化，船/鱼/纸飞机保持清晰；插画上不再放任何文字。
- 四宫格：最多 4 个分类，固定 4 列，不按分类数量改写列数；点击筛选文章，再次点击恢复全部；分类配置封面优先，缺省用 `cat-*.png`。
- 搜索入口：按 uni-halo `uh-home-banner` 的实际结构，压在插画下缘（translateY -24px）、两侧内缩 72rpx、高 96rpx 的玻璃胶囊输入框（“哈喽，想看些什么 内容 呢~”）；确认后首页原地切换为搜索结果态，不跳转独立页面。顶部不再放小搜索图标；因前面明确否掉渐变，底部用玻璃叠加/阴影衔接，不加白色渐变遮罩。
- 文章卡（Halo 式）：白卡，标题 17px/500 两行；摘要 13px/400 两行；真实封面放右上角 260×180rpx，没有封面就不显示图片（不再用分类插画充当封面）；底部左侧是浅绿置顶胶囊 + 灰色 `#分类` 标签，右侧是火箭浏览数 + 爱心点赞数，卡片间距 20rpx。

### 4.2 微语

- 页面底 `#F5F7FA`，白卡列表。
- 按天分组：今天 / 昨天 / 10 月 21 日；组内卡片只显示 `HH:mm`，不再在卡片里重复日期。
- 作者行：纯色头像 + 昵称 + 时间 + 置顶小圆点。
- 正文 13px / 1.7。
- 图片：1 张全宽，2 张两列；插画块用浅色底，照片块用实拍图。
- 底部：橙色点赞（选中填充）+ 灰色分享。
- 不加时间轴；列表就是按天分组的卡片流。

### 4.3 分类 / 搜索

**分类页（原「发现」Tab）**

- 底栏第三项改为「分类」，新画 2×2 网格图标；页面标题居中。
- 两列大卡片：分类封面优先（`/mp/categories.coverUrl`），无封面用 `cat-*.png` + 分类浅色底。
- 卡片底部是纯色半透明深色带（不用渐变），白字分类名 + `共 N 篇`；两张起排，按分类数量自然延伸。
- 点击卡片回到首页并带上 `?cat=slug`，复用首页分类筛选。

**搜索结果态（仍在首页内）**

- 搜索条是真实 input；确认后在首页原地切换：隐藏插画/公告/宫格，顶部显示「搜索」+「取消」+ 搜索条，下面直接是结果列表。
- 结果仍走 `/mp/posts?q=`，Halo 卡分页加载；无结果用插画空态；取消后回到首页。
- 不再做单独搜索落地页，也不跳转页面；分类统一交给分类页。

### 4.4 我的

- 全幅照片头图 540rpx + 纯色压暗层（`rgba(12,24,38,.48)`）；头像 66px 白描边；白字昵称；白色半透明“编辑资料”胶囊。
- 统计直接放在照片头图底部，用一条细线 + 深色半透明底带（`rgba(12,24,38,.34)`）分隔：评论 / 点赞 / 收藏；数字 15px、标签 10px，**不再单独做数据卡**。分享放右上角圆形图标。
- 按钮只保留两种：白色实底/白半透明次要按钮、天空蓝主按钮。金色只用于收藏星标/收藏态；文章置顶使用浅绿小胶囊。
- 两张服务卡：关于纸鱼 / 问题反馈，橙/蓝圆形图标。
- 四宫格：白卡、彩色线性图标：收藏（金）、历史（蓝）、评论（绿）、设置（紫）。
- 列表：开源地址 / 清除缓存 / 当前版本。
- 底部：浅蓝引用卡“记录不是为了被看见，是为了不忘记。”

### 4.5 文章详情

- 全幅照片封面 210px + 状态栏，纯图不压字；返回/分享/胶囊叠在图上。
- 白色 article sheet 上浮 12px，圆角 12px，内边距 32rpx；分类/标题/meta/作者都放在白色区域，**不要在照片上压渐变大标题**。
- 作者行 + 黄色阅读提示卡（`#FFF8E1` / `#B26A00`）。
- 正文 14px / 1.9；H2 左侧 3px 天空蓝竖条；引用浅蓝；代码块深色。
- 插画 figure：浅蓝底 + 160px 手绘插图 + 居中 caption。
- 彩色标签胶囊 + “— 完 —”。
- 评论：白底、头像、作者徽章、回复块。
- 固定底部操作栏：默认深灰；点赞选中橙、收藏选中金；评论/分享保持灰。
- 滚动超过 600px 显示右下角返回顶部悬浮按钮，点击平滑回顶；小程序走 `onPageScroll`，H5 额外监听捕获阶段 scroll 兜底。
- （P2）顶部 3px 天空蓝阅读进度条。

## 5. 插画与包体策略

### 5.1 原型阶段

第一版原型曾借 `yimo-resource-blog`（MIT）的素材做视觉校准；当前原型已全部替换为纸鱼原创插画，依沫只保留为版式参考。

### 5.2 纸鱼原创插画（已产出第一版）

- 5 个分类插画：技术（灯泡鱼）、建站（屏幕小屋）、生活（纸船）、随笔（手帐）、设计（调色盘）。
- 3 个空态：无文章（空鱼缸）、无评论（气泡鱼）、离线（雨伞鱼）。
- 8 个底栏图标：文章 / 微语 / 分类 / 我的，各一组未选中/选中。
- 1 张天空头图底（780×578）、1 张分享兜底图。
- 风格：深灰粗描边 + 2–3 个 pastel 填充 + 大量留白；透明底、无渐变、无 emoji、无 3D。
- 源文件：`docs/illustrations/src/*.svg`；导出：`docs/illustrations/png/*.png`；打包副本：`src/static/illus/`。
- 生成：`npm run gen:brand-illus`（脚本：`scripts/gen-brand-illus.mjs`）。
- 详细映射见 [`docs/illustrations/README.md`](./illustrations/README.md)。

### 5.3 包体预算

当前包内图片约 124K，其中默认横幅 116K。V2 的图片更多，必须重新分配：

| 资源 | 实际大小 | 预算 |
| --- | --- | --- |
| 天空头图底 | 24.1K | ≤26K |
| 5 个分类插画 | 18.3K | ≤30K |
| 8 个底栏图标 | 13.1K | ≤16K |
| 3 个空态插画 | 16.4K | ≤24K |
| 分享兜底图 | 6.9K | ≤10K |
| 品牌插画合计 | **77.3K** | ≤120K |
| 现有 banner + logo + 旧分享图 | 120.8K | — |
| `src/static` 图片总计 | **197.9K** | ≤200K |

- `scripts/optimize-img.mjs` 已把 `src/static/illus` 纳入 200K 总预算；当前剩余约 2.1K。
- 我的头图、详情封面建议走远程图片（插件配置/CDN）；把 `banner-1.jpg` 远程化后可再释放约 114K。
- 远程图片必须 HTTPS、配置 download 域名，加载失败回退纯色天空/插画，不用渐变。
- 如果后续增加插画，优先减少数量，而不是把图标压到不可读。

## 6. 对 V1 技术方案的修改

V1 的以下部分继续有效：4 Tab 信息架构、`zz-navbar` / `zz-tabbar` / `zz-post-card` / `zz-empty` / `zz-skeleton` 组件拆分、接口约束、审核模式、性能与 QA。

需要修改：

1. **Token**：用 V2 色板替换 V1 的纸感色板；删除 `--zz-paper` 暖色、墨绿、珊瑚。
2. **底栏**：`zz-tabbar` 改为 PNG 图标背景；选中切换 `--tab-*-on`；高度 58px；不再用 TDesign 图标。
3. **导航**：首页导航透明叠在天空图上；微语/分类/搜索用浅色 sticky 导航；我的/详情用深色状态栏 + 浮层按钮。
4. **首页结构**：天空插画作为完整首屏（无文字，背景轻微虚化），搜索输入条、公告、四宫格随后，然后直接是文章列表；**取消轮播**；移除品牌字标和顶部小搜索，搜索改为首屏大输入条，确认后原地显示结果；四宫格最多 4 个分类。
5. **详情**：封面改为全幅照片；新增黄色提示卡；操作栏图标改为彩色；阅读进度保留。
6. **我的**：改为照片头图 + 头部数据带 + 服务卡 + 四宫格 + 列表 + 引用卡；删除 V1 的纸感身份卡和单独的数据卡。
7. **发现 → 分类**：底栏第三项改为「分类」，两列大卡片（封面优先/插画兜底），点击回首页筛选；搜索留在首页内做结果态，不再单独建搜索页。
8. **资源**：V1 的“CSS/图标优先”改为“插画优先 + 远程照片”；包体预算按 5.3 执行。
9. **验收**：增加“四个标志性模块”检查：天空头图、四宫格插画、头部数据带、分类大卡片页。

## 8. 风险

| 风险 | 对策 |
| --- | --- |
| 直接照搬参考站，失去纸鱼品牌 | 原型只借结构/插画语言；正式插画、文案、分类全部换成纸鱼自己的 |
| 插画太多导致包体超 200K | 当前插画 71.8K、总图片 192.5K；`optimize-img.mjs` 构建前卡 200K；照片建议远程 |
| 首页天空图与状态栏色差 | 状态栏用天空图顶部采样色 `#BEEBFF`；远程图需同步取色 |
| 照片头图上的白字看不清 | 统一加 40–55% 纯色遮罩；头像白描边；编辑按钮白底深字；统计放深色底带 |
| 彩色过多显得乱 | 一屏一个主色区域：天空蓝底 + 白卡 + 分类色只出现在插画/标签 |
| 参考站广告/积分被误带入 | 明确不做；头部数据带只放身份/统计/分享 |
| 底栏 PNG 在低端机模糊 | 导出 2×/3×，按 24px 显示；优先 PNG8 |

## 9. 验收标准

- [ ] 首页是完整天空插画首屏（背景轻微虚化、无文字），两侧内缩的大搜索条、白色公告卡、四宫格随后，直接进入最新文章；页面没有任何轮播图；顶部没有品牌字标和小搜索图标。
- [ ] 底栏是厚描边 PNG 图标，选中 `#60C2FF`，未选中 `#A8B4C8`。
- [ ] 文章卡是 Halo 式：标题/摘要在上、右上角仅真实封面、底部浅绿置顶 + `#分类` + 火箭浏览 + 爱心点赞。
- [ ] 底栏第三项为「分类」，分类页是两列大卡片（封面优先/插画兜底、纯色底带 + 白字）。
- [ ] 首页大搜索条是真实输入框，确认后原地显示搜索结果，不跳转独立页面；取消后回到首页。
- [ ] 我的页是照片头图 + 头部数据带 + 服务卡 + 四宫格。
- [ ] 详情页是全幅封面 + 黄色提示卡 + 固定操作栏 + 返回顶部。
- [ ] 页面无米色纸底、无英文小标签、无点阵背景、无设计系统侧栏。
- [ ] 无 CSS 渐变；按钮/头像/深色底带/引用卡/页面背景均为纯色。
- [ ] 无 emoji；所有图标来自 PNG 插画或图标库。
- [ ] 文章卡圆角 20rpx（10px），头图 28rpx（14px），图片 8px，没有全站 20px 大圆角。
- [ ] 包内图片 ≤200K（当前 197.9K）；无 GIF；照片建议走远程。
- [ ] 审核模式、登录/评论/点赞/收藏开关仍逐页生效。
- [ ] iOS/Android 小屏、大屏、刘海/胶囊避让通过。

## 10. 结论

V2 不再尝试“发明一种纸鱼风格”，而是先把参考站真正有效的视觉配方学到位：

**天空图建立第一屏情绪，四宫格插画建立亲和力，白卡保证内容密度，照片头图 + 数据底带建立真实感和个人页记忆点，彩色底栏建立品牌识别。**

纸鱼的差异化放在内容、文案和原创插画上，而不是继续在米色/墨绿/英文小标签上做“设计感”。
